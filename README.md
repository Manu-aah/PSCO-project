Foundation 

Game 1: Dice Patterns Challenge 


Rules: 

  Player rolls five dice 

  May re-roll up to two times, choosing which dice to keep. 

  Dice will always be unordered 

  Final pattern is scored as follows: 

•Five of a Kind – 50 pts 

• Four of a Kind – 40 pts 

• Full House (3 matching + 2 matching) – 35 pts 

• Straight (1-5 or 2-6) – 30 pts 

• Three of a Kind – 25 pts 

• Two Pairs – 20 pts 

• One Pair – 10 pts 

• Optional: Allow for multiple rounds and cumulative scoring. 

 

Game 2: Dice Grid Puzzle 

Goal: Fill a 3x3 grid with dice rolls to form high-scoring patterns. 

Rules: 

• Player rolls one die at a time and places it in an empty cell 

• Repeat until all 9 cells are filled 

• Score each row and column: 

• Three of a Kind – 15 pts 

• Straight – 12 pts 

• Pair – 8 pts 

• All Different – 5 pts 

• Total score is the sum of all row and column score 

 

Game 3: Dice Codebreaker 

Goal: Guess a secret 4-dice code generated by the computer. 

Rules: 

• Code is randomly generated (e.g., [2, 5, 3, 6]) 

• Player makes guesses (e.g., [2, 3, 4, 6]) 

• After each guess, feedback is given: 

• Correct number in correct position 

• Correct number in wrong position 

• Game ends when code is guessed or max attempts reached 


 
Game 4: Dice Blackjack 

Goal: Compete against the computer by rolling dice. The goal is to hit 12, or get the closest total to 12; the closest value wins. 

Rules: 
  Players need to choose an amount of points they want to put at stake to play the game 

  The game will roll 2 dice automatically for the player before the computer rolls its dice 

  The player/computer can choose to either “Hit” which means they want to roll another dice or “Stand” which means they want to keep the current dice value 

  The computer has a special condition, It always “Hits” if the computers dice value is below 17 and always “Stands” on or above 17. 

  The player can roll the dice as long as the total value doesn’t exceed 12 

  If the value exceeds 12 the dice will be a bust and the the points put on stake will be lost. 

  If the players dice value is closer to 12 than computers dice, the player wins and vice versa.
